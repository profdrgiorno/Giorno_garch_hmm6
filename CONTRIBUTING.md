# Contributing / reporting an issue

This is a research working release. Please identify the exact code commit, Python/scientific-library versions, DGP scenario and path ID, model key, random seed and complete traceback or numerical anomaly.

For statistical issues, distinguish (i) a theorem proof question, (ii) parameter identification, (iii) optimizer reliability, (iv) an OOS comparison, or (v) source-data provenance. Please do not submit untracked edits to source datasets or remove failed optimizer paths to improve a ranking.

For changes to a numerical method, retain the original result and add a separately named corrected dataset with a clear changelog and comparison. No third-party software license has yet been selected; code contributions require the research owner's permission and agreement on licensing.
